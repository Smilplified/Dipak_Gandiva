# CRM Dashboard

A clean and professional CRM dashboard built with Next.js 15 and Ant Design 5.

## Features

- **Dashboard Overview** - Revenue stats, pipeline metrics, and key KPIs
- **Sales Charts** - Revenue trends and pipeline by stage
- **Deals Table** - Recent deals with stage and probability tracking
- **Activity Feed** - Real-time activity timeline
- **Responsive Layout** - Sidebar navigation, search, and user menu

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Next.js 15** - React framework with App Router
- **Ant Design 5** - UI component library
- **Recharts** - Charts and data visualization
- **TypeScript** - Type safety
